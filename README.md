# 🇿🇼 FAMBA — Zimbabwe Drive

> *"Famba"* — Shona: *to travel, to move, to journey.*

An arcade web driving game taking you on a sunset road trip across the scenic highways and vibrant landscapes of Zimbabwe in a classic kombi (commuter omnibus). Steer, pick up passengers, collect fares, navigate traffic, and reach your destination before dusk!

---

## 🎮 Game Features

- **Iconic Zimbabwean Routes**:
  - **Route 01**: Harare → Mutare (Scenic Eastern Highlands highway)
  - **Route 02**: Bulawayo → Victoria Falls (Through the heart of Matabeleland to the majestic falls)
  - **Route 03**: Harare → Masvingo (Journey towards the ancient Great Zimbabwe monument)
- **Classic Kombi Road Trip Experience**: Procedural retro road rendering with smooth canvas animations.
- **Fare Collection & Traffic**: Manage speed, overtake vehicles, pick up commuters, and collect fares along the highway.
- **Atmospheric Soundscapes**: Engine audio, horn, and ambient travel effects.
- **Fast & Responsive**: Lightweight static bundle designed for instant loading on desktop and mobile web browsers.

## 🕹️ Controls

| Action | Keyboard Key |
| :--- | :--- |
| **Steer Left / Right** | <kbd>←</kbd> / <kbd>→</kbd> or <kbd>A</kbd> / <kbd>D</kbd> |
| **Accelerate / Speed Up** | <kbd>↑</kbd> or <kbd>W</kbd> |
| **Brake / Slow Down** | <kbd>↓</kbd> or <kbd>S</kbd> |
| **Toggle Audio / Engine Sound** | Top menu button or <kbd>M</kbd> |

## 🚀 How to Play Locally

Simply serve the project folder using any static file server or development server:

```bash
# Using Python
python -m http.server 8000

# Or using Node npx serve
npx serve .
```

Open `http://localhost:8000` in your web browser and click **TANGA ↗** to start your journey.
